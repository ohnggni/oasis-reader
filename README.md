# OG Reader

**북오아시스(BookOasis) 전용** 안드로이드 전자책·만화 리더입니다. 북오아시스 공식 앱이 아닌 개인 프로젝트입니다.
OPDS 카탈로그에서 책을 받아 폰에 보관하고, 오프라인에서도 읽어요. 폴더블(갤럭시 폴드) 화면에 맞춰 다듬었어요.

## 할 수 있는 것

| | |
|---|---|
| **EPUB** | 쪽 넘김(밀기·종이 말림·덮기), 글꼴·크기·줄간격·여백(책마다 기억), 배경 색 9가지, 내 글꼴 추가, 목차, 하이라이트·메모, 진행률 |
| **TXT** | 받을 때 장(1화·제1장·Chapter 1 …)을 찾아 EPUB처럼 변환. UTF-8 / CP949 자동 판별 |
| **PDF** | 쪽 단위로 넘기기·맞쪽·확대 (만화 뷰어와 같은 조작). 글자 크기 재배치는 안 됨, 암호 걸린 PDF는 못 엶 |
| **CBZ / ZIP (만화·웹툰)** | 책처럼 넘기기, 가로모드 맞쪽 보기(여백 없이), 오른쪽→왼쪽 넘김, 확대, 세로 스크롤(웹툰) |
| **카탈로그** | OPDS 1.x / 2.0, Basic 인증, 서버 여러 개, 폴더 정렬·검색 |
| **정리된 카탈로그** (선택) | oasis-meta를 띄우면 시리즈별 표지 목록, 정리된 제목, 실제 파일 날짜 정렬, 책 상세·줄거리 |
| **서재** | 정렬, 이름 바꾸기, 삭제, 내 폰·구글 드라이브에서 가져오기 |
| **바로 읽기** | 서재에 담지 않고 임시로 받아 바로 열기. 한도(기본 2GB, 최대 50GB)를 넘으면 오래 안 본 책 파일부터 정리하고, 읽은 위치·하이라이트는 남아요. 📌로 계속 보관 |
| **기타** | 독서 통계, 화면 꺼짐 방지, 백업/복원 (책 파일 포함 여부 선택, 폰 교체 시 그대로 이전) |

## 설치

[Releases](../../releases)에서 최신 `OasisReader.apk`를 받아 설치하세요 (안드로이드 10 이상).
업데이트도 같은 방법으로 덮어 설치하면 돼요 (서명 키가 같아서 데이터가 유지돼요).

## 처음 설정

1. ☰ → **서버에서 책 찾기** → 서버 추가
2. **OPDS 주소**: `https://<북오아시스 주소>/opds`
   - 집 안에서만 쓴다면 `http://192.168.x.x:<포트>/opds`도 돼요. 단 http는 암호화되지 않으니 외부망에서는 https를 쓰세요.
3. **아이디 / 비밀번호**: 북오아시스 계정 (비밀번호는 폰 안에서만 암호화 보관)
4. **메타 API 주소**: oasis-meta를 띄웠다면 그 주소, 아니면 비워두세요
5. **메타 DB**: 성인 DB 카탈로그(`/opds` 성인용)면 "성인" (북오아시스 관리자 계정만)
6. **연결 확인** → 저장

oasis-meta 없이도 OPDS 폴더 목록으로 모든 기능을 쓸 수 있어요.
oasis-meta가 있으면 카탈로그가 "시리즈 → 권" 구조의 표지 목록으로 바뀌어요.

## oasis-meta (선택)

북오아시스 OPDS에는 시리즈명, 실제 파일 날짜, 표지 경로, 정리된 제목이 없어서(`[만화] 1` 같은 제목, 모든 날짜가 요청 시각)
북오아시스 DB를 **읽기 전용**으로 조회하는 작은 API를 옆에 띄워서 보완해요.
설치: https://github.com/ohnggni/oasis-meta (`git clone` 후 `bash install.sh`). 앱의 **설정 › 메타 API 안내**에도 같은 내용이 있습니다.

## 빌드

```bash
gradle assembleDebug        # Gradle 8.11 · JDK 17
```

GitHub Actions가 `main`에 push할 때마다 테스트·빌드하고 Release를 만들어요.
고정 서명 키는 저장소 Secrets(`ANDROID_KEYSTORE_B64` = keystore 파일 base64, `ANDROID_KEYSTORE_PASSWORD`)로 넣어요. (없으면 CI 빌드가 멈춰요.)
포크해서 쓰면 본인 키를 만들어 넣으세요 (`keytool -genkeypair -v -keystore oasis.jks -alias oasisreader -keyalg RSA -keysize 4096 -validity 36500`, 별칭은 `oasisreader`).

## 데이터

- 책·진행률·하이라이트는 폰 안(앱 전용 저장소)에만 있어요. 외부 서버로 보내는 건 카탈로그 요청과 다운로드뿐이에요.
- 구글 클라우드 자동 백업에는 설정·진행률만 들어가고 책 파일은 빠져요. 폰 교체(기기 간 전송)에는 책도 들어가요.
