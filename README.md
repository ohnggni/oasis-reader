# OG 📖 Reader

**안드로이드 전자책 · 만화 · PDF · 오디오북 앱**입니다.
OPDS 카탈로그 서버에서 책을 받아 폰에 보관하고 읽으며, 지원하는 서버의 오디오북을 듣습니다. 폰의 파일을 직접 가져와 읽을 수도 있습니다.
폴더블(갤럭시 폴드) 화면에 맞춰 다듬었습니다.

**⬇️ [최신 APK 내려받기](https://github.com/ohnggni/oasis-reader/releases/latest/download/OasisReader.apk)** · [릴리스 목록](https://github.com/ohnggni/oasis-reader/releases)
— 안드로이드 10 이상 · 무료 · 광고 없음 · 앱 안에서 업데이트

## 📖 읽기

- **EPUB · TXT · PDF · 만화(CBZ/ZIP)** — 책처럼 넘기기(밀기 · 종이 말림 · 덮기) 또는 스크롤, 폴드 펼치면 맞쪽
- 글꼴(내 글꼴 추가) · 크기 · 줄간격 · 여백 · 배경을 **책마다** 기억, 기본값 따로
- 하이라이트 · 메모 · 책갈피 · 본문 검색, 하이라이트를 마크다운 / JSON으로 내보내기
- 글자를 골라 **찾아보기** — 파파고 · 구글 번역 · 네이버 사전 · 위키백과 · 브라우저 검색
- 각주 팝업, 그림 길게 눌러 크게 보기, 블루투스 페이지 리모컨 · 볼륨 키 넘김
- **소리 내 읽기(TTS)** — 읽는 문장 표시, 화면 꺼도 계속, 수면 타이머, 삼성 · 구글 목소리 선택
- TXT는 받을 때 장(1화 · 제1장 · Chapter 1 …)을 찾아 EPUB처럼 변환 (UTF-8 / CP949 자동 판별)
- 만화 — 오른쪽→왼쪽(일본 만화), 웹툰 세로 스크롤, 두 번 눌러 확대

## 🎧 오디오북

- 서버 설정에서 종류를 **오디오북**으로 추가 — 서버 계정 그대로
- 들은 위치가 서버에 저장돼서 다른 기기 · 웹과 **이어 듣기**
- 15초 뒤로 · 30초 앞으로 · 속도 · 수면 타이머, 잠금 화면 · 이어폰 버튼 조작
- **폰에 받기** — 책 전체 또는 트랙 하나씩, 앱을 닫아도 백그라운드로 받고 끊기면 이어받기, 와이파이에서만 받기
- 받기 관리 화면에서 받는 중 · 대기 · 받은 트랙을 한눈에

## 📚 서재 · 기록

- **바로 읽기**(임시 보관, 한도를 넘으면 오래 안 본 책 파일부터 정리) / **서재에 담기**(계속 보관)
- 표지 오른쪽 아래 표시: 초록 ⬇ = 폰에 보관, 회색 ☁ = 서버에만 있거나 임시 보관
- 내 책장 **컬렉션**, 종류 · 읽음 상태 필터, 종류별 정렬(순서 직접 지정)
- **독서 통계** — 오늘 · 연속 일수 · 월간/연간, 히트맵, 오디오북 들은 시간 포함
- **읽은 위치 동기화** — KOReader 동기화(kosync) 방식으로 기기끼리
- 백업 zip 하나로 기기 옮기기 (서버 비밀번호는 빼고)

## 🧩 더 편하게: 메타 API (선택)

서버에 메타 API([**oasis-meta**](https://github.com/ohnggni/oasis-meta), 작은 Docker 컨테이너)를 함께 띄우면, "서버에서 책 찾기"가 폴더 목록 대신 이렇게 바뀝니다.

- 📚 **시리즈별 표지 목록**과 정리된 제목, 최근 올라온 순 정렬
- 책 상세에 **줄거리**
- 🗂️ 카테고리 여러 개 · 📄 형식(EPUB/TXT/PDF/만화) 필터, ⭐ 자주 쓰는 조합 저장
- 목록마다 **전체 개수** 표시

서버 DB를 **읽기만** 하는 선택 기능이고, 없어도 앱은 OPDS만으로 그대로 동작합니다. 지원 서버와 설치 방법: https://github.com/ohnggni/oasis-meta

## 🚀 시작하기

1. 위 **APK 내려받기**로 설치 (처음 한 번 "출처를 알 수 없는 앱 허용"). 이후 업데이트는 앱이 알려 줍니다.
2. 서재 ☰ → **서버에서 책 찾기** → ⚙️에서 서버 추가
   - 책: 종류 **일반**(또는 성인), OPDS 주소(예: `https://<내 서버>/opds`), 서버 아이디 · 비밀번호
     (집 안에서만 쓴다면 `http://192.168.x.x:<포트>/opds`도 됩니다. http는 암호화되지 않으니 외부망에서는 https를 쓰세요.)
   - 오디오북: 종류 **오디오북**, 서버 주소 · 계정
   - 메타 API 주소: oasis-meta를 띄웠다면 그 주소, 아니면 비워 둡니다
3. 자세한 사용법은 앱의 설정 › **사용 안내** ([guide.md](app/src/main/assets/guide.md))

## 🔒 개인정보 · 파일

- 책 · 읽은 위치 · 하이라이트 · 설정은 폰 안(앱 전용 저장소)에만 저장됩니다. 서버에는 목록 조회 · 다운로드와 (켠 경우) 읽은 위치, 오디오북 들은 위치만 보냅니다.
- 서버 비밀번호는 폰 안에서 암호화해 보관하고 백업에 넣지 않습니다.
- 받은 파일은 앱 안에만 있어 다른 앱에서 보이지 않고, 오디오북은 그 폰에서만 풀리게 암호화해 둡니다.
- 구글 클라우드 자동 백업에는 설정 · 진행률만 들어가고 책 파일은 빠집니다. 폰 간 이전(Smart Switch)에는 책은 들어가고 받은 오디오북은 빠집니다(새 폰에서 다시 받음).

## 빌드

```bash
gradle assembleDebug        # Gradle 8.11 · JDK 17
```

- GitHub Actions가 `main`에 push할 때마다 테스트 · 빌드하고 Release를 만듭니다. 버전은 `VERSION` 파일(예: `1.0`) + 빌드 번호 → `1.0.<run>`. 문서(`*.md`)만 바뀐 push는 빌드하지 않습니다.
- 고정 서명 키는 저장소 Secrets(`ANDROID_KEYSTORE_B64` = keystore 파일 base64, `ANDROID_KEYSTORE_PASSWORD`)로 넣습니다. 없으면 CI 빌드가 멈춥니다.
- 포크해서 쓰면 본인 키를 만들어 넣으세요 (`keytool -genkeypair -v -keystore oasis.jks -alias oasisreader -keyalg RSA -keysize 4096 -validity 36500`, 별칭은 `oasisreader`).
