# OG Reader

**북오아시스(BookOasis) 전용 전자책·만화 리더입니다.**

북오아시스 서버의 OPDS 카탈로그에서 책을 받아 휴대폰에 보관하고 읽습니다. EPUB · TXT · PDF · CBZ/ZIP을 지원합니다.

- 이 앱은 북오아시스 공식 앱이 아니며, 북오아시스 개발자와 관계없는 개인 프로젝트입니다.
- 정리된 카탈로그(시리즈·표지·줄거리)는 서버 옆에 oasis-meta를 따로 띄운 경우에만 동작합니다. 설정 › 메타 API 안내를 참고하십시오.
- 책·읽은 위치·하이라이트·설정은 이 기기 안에만 저장됩니다. 서버에는 카탈로그 조회와 다운로드 요청만 보냅니다.
