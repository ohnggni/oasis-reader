# 메타 API (oasis-meta)

> **북오아시스 서버용 부가 기능입니다.** 없어도 앱은 OPDS 폴더 목록으로 그대로 동작합니다. 필요한 분만 설치하시면 됩니다.

서버 옆에 oasis-meta를 띄우고 앱의 서버 설정 › **메타 API 주소**에 넣으면, "서버에서 책 찾기"에서 이런 것이 됩니다.

- 📚 **시리즈별 보기**: 폴더 대신 시리즈 단위 표지 목록
- 정리된 제목과 **파일 날짜 순** 정렬 (최근 올라온 책부터)
- 책 상세에 **줄거리**
- 🗂️ 카테고리 여러 개 · 📄 형식(EPUB·TXT·PDF·만화) 필터, ⭐ 보기 프리셋
- 목록마다 **전체 개수** ("시리즈 N개 · N권")

북오아시스 DB를 읽기만 하는 작은 Docker 컨테이너입니다. 책 파일이나 드라이브에는 접근하지 않습니다.
⚠️ 라이브러리별 사용자 권한은 적용하지 않으니 혼자 쓰는 서버에서만 쓰십시오.
