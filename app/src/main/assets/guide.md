# 사용 안내

OG Reader를 처음 쓰시는 분을 위한 안내입니다. 전자책(EPUB·TXT), 만화(CBZ·ZIP), PDF, 오디오북을 한 앱에서 보고 듣습니다.

## 1. 서버 연결

1. 서재 왼쪽 위 ☰ → **서버에서 책 찾기**
2. ⚙️ 서버 설정에서 서버를 추가합니다. 맨 위에서 **종류**를 고릅니다.
   - **일반 / 성인**: 책 서버(OPDS). 주소는 `https://<서버 주소>/opds`, 아이디·비밀번호는 서버 계정
   - **오디오북**: 북오아시스의 오디오북. 북오아시스 주소와 계정
   - 메타 API 주소: oasis-meta를 설치했다면 그 주소, 아니면 비워 둡니다 (설정 › 메타 API 안내)
3. **연결 확인** → 저장. 서버를 여러 개 두면 "서버에서 책 찾기"에서 고릅니다.

oasis-meta가 없어도 폴더 목록으로 모든 책을 받을 수 있습니다. 설치하면 시리즈별 표지 목록, 정리된 제목, 줄거리, 카테고리·형식 필터가 생깁니다.

## 2. 책 찾기 · 받기

- **바로 읽기**: 서재에 담지 않고 임시로 받아 바로 엽니다. 임시 보관 한도를 넘으면 오래 안 본 책의 파일부터 정리되며, 읽은 위치와 하이라이트는 남습니다. 다시 열면 자동으로 다시 받습니다.
- **서재에 담기**: 계속 보관합니다. 임시로 받은 책은 서재에서 길게 눌러 "📌 서재에 보관"으로 바꿀 수 있습니다.
- 내 폰이나 구글 드라이브의 파일은 ☰ → **파일에서 가져오기**로 넣습니다.
- 폴더째 넣으려면 ☰ → **폴더에서 가져오기**: 하위 폴더까지 책을 찾아 한 번에 담고, 책 폴더마다(또는 고른 폴더 하나로) 📚 컬렉션으로 묶을 수 있습니다. 같은 폴더를 다시 가져오면 새 책만 추가됩니다. 책은 앱 안으로 복사됩니다.
- 목록 위 필터 줄: 🗂️ 카테고리(여러 개) · 📄 형식(EPUB·TXT·PDF·만화) · ⭐ 프리셋(자주 쓰는 조합 저장) · 🔽🔼 정렬 · 🔲 타일 / 📃 목록 · 📐 크기. 필터 아래에 찾은 개수가 나옵니다.
- 시리즈 화면의 "모두 담기"는 같은 이름의 📚 컬렉션으로 묶을지 물어봅니다.
- 📚 시리즈별 / 📂 폴더별: 메타 API가 있으면 시리즈별로, 없으면 서버 폴더 그대로 봅니다.

지원 형식: EPUB · TXT · PDF · CBZ/ZIP(만화) · 오디오북(북오아시스)

## 3. 서재

- **표지 오른쪽 아래 표시**
  - 초록 ⬇: 폰에 받아 둔 것 (서재에 보관, 인터넷 없이 봄)
  - 회색 ☁: 서버에만 있거나 임시 보관(캐시)에 있는 것. 임시 보관 파일은 공간이 모자라면 정리될 수 있습니다
  - 오디오북을 받는 동안에는 둘레에 진행 고리가 돕니다
- 제목 앞에 종류가 나옵니다: 📖 책 · 🖼️ 만화 · 📄 PDF · 🎧 오디오북
- **필터 줄**: 🔲 타일 / 📃 목록 · 📐 크기 · 정렬 · 📚 컬렉션 · 🏷️ 종류 · 🔖 읽음 상태(전체·읽는 중·안 읽음·다 읽음)
- **정렬**: 읽은 날짜 · 추가한 날짜 · 제목 · 저자 · 진행률 · **종류**. 종류 순서는 정렬 메뉴의 "↕️ 종류 순서 정하기"에서 바꿉니다.
- **📚 컬렉션**: 내 책장입니다 ("출퇴근길", "아이들과 함께" …). 📚 칩에서 새 컬렉션을 만들고, 책을 길게 눌러 "📚 컬렉션에 넣기". 한 책을 여러 컬렉션에 넣을 수 있고, 컬렉션을 지워도 책은 서재에 남습니다.
- 책을 길게 누르거나 ⋮을 누르면 책 정보, 컬렉션, 이름 바꾸기, 보관, 하이라이트 내보내기, 오디오북 받기, 삭제가 나옵니다.
- 서재 위 부제: 서재 권수와 오늘 읽은(들은) 시간.

## 4. 책 읽기 (EPUB · TXT)

화면을 세로로 셋으로 나눠 생각하시면 됩니다.

| 누르는 곳 | 동작 |
|---|---|
| 왼쪽 30% | 이전 쪽 |
| 가운데 | 상단바 보이기 / 숨기기 |
| 오른쪽 30% | 다음 쪽 |
| 맨 위 장 제목 줄 | 상단바 보이기 (어디서나) |

- 좌우로 밀어도 넘어갑니다. 넘김 효과가 **종이 말림**이면 모서리가 손가락을 따라 말립니다.
- **그림**은 길게 누르면 크게 봅니다. 짧게 누르면 다른 곳과 똑같이 넘기거나 상단바를 띄웁니다.
- 글자를 길게 눌러 고르면 **하이라이트·메모**, **찾아보기**(번역·사전 앱, 네이버 사전, 위키백과, 브라우저 검색)가 나옵니다. 찾아보기 앱과 순서는 설정 › 읽기 › 찾아보기 앱.
- **각주** 번호를 누르면 아래에 각주 내용이 뜹니다. "본문으로"나 책 안의 링크로 다른 곳에 가면 아래에 "↩️ 원래 보던 곳으로"가 떠서 한 번에 돌아올 수 있습니다.
- 상단바를 띄우면 아래에 위치 슬라이더가 함께 뜹니다. 끌면 장 제목과 %가 보이고, 놓으면 이동합니다.
- 블루투스 페이지 리모컨·키보드: →·↓·Page Down·Space는 다음 쪽, ←·↑·Page Up은 이전 쪽. 볼륨 버튼은 설정 › 리모컨 · 키보드에서 켭니다.

### 상단바

| 버튼 | 내용 |
|---|---|
| ☀️ 화면 | 밝기, 배경, 화면 켜짐 유지, 상단바 자동 숨김 |
| 가 글자 | 글꼴(내 글꼴 추가), 크기·굵기·줄간격, 책 디자인 사용 |
| ▤ 쪽 | 책처럼 넘기기 / 스크롤, 넘김 효과·속도, 여백 |
| ☰ 이동 | 목차, 본문 검색, 소리 내 읽기, 책갈피, 이 책의 하이라이트, 하이라이트 내보내기, 다 읽음 |

- 슬라이더 왼쪽의 − + 버튼으로 한 칸씩 조절합니다 (길게 누르면 계속).
- 설정은 **책마다 따로 기억**됩니다. 맨 아래 **기본값으로 저장**을 누르면 다른 책에도 적용되고, **되돌리기**를 누르면 이 책도 기본값을 따릅니다. 기본값은 설정 › 읽기 › 읽기 기본값에서도 정합니다.
- **책갈피**: 상단바 왼쪽 책갈피 표시를 누르면 저장, 다시 누르면 지움. 목록은 ☰ 이동 › 책갈피.
- **본문 검색**: 띄어쓰기 개수와 대소문자는 가리지 않습니다. 결과를 누르면 그 자리로 가서 찾은 낱말을 잠시 표시합니다.
- **소리 내 읽기**: ☰ 이동 › 소리 내 읽기. 지금 쪽의 첫 문장부터 읽고, 읽는 문장에 옅은 색이 따라가며 쪽과 장이 저절로 넘어갑니다.
  - 아래 막대(끌어서 옮김): ⏮ 이전 문장 · ⏸ · ⏭ 다음 문장 · 빠르기 · 🌙 수면 타이머 · 🎙 목소리 · ✕
  - 화면을 끄거나 다른 앱으로 가도 계속 읽고, 알림창·잠금 화면·이어폰 버튼으로 조작합니다.
  - 🎙 목소리: 음성 엔진(삼성·구글 등)과 목소리·음높이를 고릅니다. 설정 › 읽기 › 소리 내 읽기 목소리에서도 바꿉니다.
- **하이라이트 내보내기**: ☰ 이동 › 하이라이트 내보내기(마크다운). 모든 하이라이트는 서재 ☰ › 하이라이트 › ⋮ › 전체 내보내기(JSON).
- 상단바가 숨어 있는 동안에는 화면 가장자리 가운데 부분의 뒤로 가기 제스처가 꺼집니다 (쪽 넘김과 겹치지 않도록). 나가려면 가운데를 눌러 상단바를 띄운 뒤 ← 를 누릅니다.

## 5. 만화 · PDF

- 왼쪽/오른쪽 30%를 누르거나 밀어서 넘깁니다. 가운데를 누르면 상단바가 뜹니다.
- 두 손가락으로 벌리거나 두 번 누르면 확대됩니다.
- 폴드를 펼치면 맞쪽(두 쪽)으로 보입니다.
- 상단바: ☀️ 화면 · ▣ 보기(책처럼 넘기기 / 세로 스크롤(웹툰), 오른쪽→왼쪽(일본 만화), 맞쪽) · ⇆ 넘김 · ☰ 이동

## 6. 오디오북 (북오아시스)

- 설정 › 서버 › ➕ 에서 종류를 **오디오북**으로 추가한 뒤, ☰ → 서버에서 책 찾기에서 그 서버를 고릅니다.
- 목록: ⭐ 프리셋 · 🗂️ 카테고리 · 🔖 다 듣지 않음/다 들음 · 정렬. 다 들은 책 앞에 ✅.
- 책을 누르면 트랙 목록이 나옵니다. **이어 듣기**는 북오아시스에 저장된 위치부터, 트랙을 누르면 그 트랙 처음부터.
- 플레이어: ⏮ · ↺15 · ⏯ · 30↻ · ⏭, 속도, 🌙 수면 타이머(분·트랙 끝). 화면을 꺼도 계속 들리고 알림창·잠금 화면·이어폰으로 조작합니다. 이어폰을 빼면 멈춥니다.
- 들은 위치는 15초마다·멈출 때 북오아시스에 저장됩니다. 웹에서 이어 들을 수 있고, 앱에서 다시 열 때 웹이나 다른 기기에서 그 뒤에 들었으면(되감기 포함) 그 자리로 갑니다. 인터넷이 없을 때 들은 위치는 연결되면 보냅니다.
- 들은 오디오북은 서재에 저절로 담깁니다. 서재에서 누르면 들은 자리부터 이어 듣고, 서재 아래 재생 막대로 멈추거나(⏸) 끝냅니다(✕).
- 들은 시간은 독서 통계에 🎧로 따로 나옵니다.

### 폰에 받기 (오프라인)

- 상세 화면의 "⬇️ 폰에 받기"(책 전체) 또는 트랙 옆 ⬇️(트랙 하나), 서재에서 길게 눌러 "⬇️ 폰에 받기".
- 앱을 닫거나 화면을 꺼도 계속 받고, 알림에 진행률과 "모두 취소"가 나옵니다. 인터넷이 끊기면 연결될 때 이어서 받습니다.
- **⬇️ 받기 관리** (서재 ☰): 받는 중·대기·실패·일부 받음·다 받음을 책별로 보고, 펼치면 트랙마다 ✅ 받음 · 45% 받는 중 · ⏳ 대기 · ⬇️ 받기. 트랙 하나씩 받거나 지웁니다. 사용 용량·남은 공간, ⏸️ 모두 멈춤, **📶 와이파이에서만 받기**.
- 일부만 받은 책은 받은 트랙은 폰에서, 나머지는 스트리밍으로 듣습니다.

## 7. 독서 통계

서재 ☰ › 독서 통계. 오늘·연속 일수·이번 달·올해 다 읽은 권수, 총 독서 시간(🎧 들은 시간 따로), 하이라이트 수, 일간 히트맵과 월간·연간 막대, 책별 시간. 책을 누르면 바로 엽니다.

## 8. 설정

- **화면**: 앱 전체 밝게 / 어둡게 / 시스템 따라가기
- **읽기**: 읽기 기본값, 찾아보기 앱, 소리 내 읽기 목소리
- **저장 공간**: 앱 전체 용량과 폰 남은 공간, 보관한 책 · 받은 오디오북 · 임시 보관 · 기타별 용량
- **바로 읽기**: 임시 보관 한도 (기본 2GB, 최대 50GB)
- **백업 · 기기 변경** (실험적 기능): 서재·읽은 위치·하이라이트·컬렉션·통계·설정을 zip 하나로 저장합니다. 책 파일은 폰에서 직접 넣은 책만 들어가고, 서버에서 받은 책과 오디오북은 새 폰에서 서버에서 다시 받습니다. 서버 비밀번호는 백업되지 않습니다.
- **받은 파일 보호**: 받은 책·오디오북은 앱 전용 공간에 있어 다른 앱이나 파일 관리자에서 보이지 않습니다. 오디오북은 이 폰에서만 풀리는 키로 암호화해 둡니다.
- **업데이트**: 새 버전이 나오면 서재 위에 알림 띠가 뜹니다. "업데이트"를 누르면 받아서 설치 화면을 엽니다 (처음 한 번은 "이 출처 허용"). 설정 › 정보 › 업데이트 확인으로 바로 확인할 수도 있습니다.

## 9. 진행 동기화

북오아시스 서버를 거쳐 **읽은 위치**를 기기끼리 맞춥니다.

**준비**: 북오아시스 웹 → 계정 메뉴 → KOReader 동기화에서 동기화 비밀번호를 정한 뒤, 앱의 설정 › 읽은 위치 동기화에서 연결합니다.

| 무엇을 | 상대 | EPUB·TXT | 만화·PDF |
|---|---|---|---|
| 읽은 위치 | 다른 OG Reader | ✅ 장 안 위치까지 | ✅ 쪽 |
| 읽은 위치 | KOReader 기기 | △ 장 시작까지 | ✅ 쪽 |
| 읽은 위치 | 북오아시스 웹 | ❌ | ✅ 쪽 (웹 "최근 읽은 도서"에도 뜸) |
| 하이라이트·메모·설정 | 어디든 | ❌ (백업으로 옮기세요) | ❌ |

- **언제 올리나**: 1분 이상 읽었거나 2쪽 이상 넘긴 뒤, 멈췄을 때·앱을 내렸을 때·책을 닫을 때.
- **언제 받나**: 책을 열 때. 다른 기기에서 더 읽었으면 그 위치로 갈지 물어봅니다. 서재에는 그런 책에 "⇄ %"가 붙습니다.
- 책은 파일 내용으로 구분하므로 같은 파일을 받은 기기끼리만 맞춰집니다.
- 오디오북의 들은 위치는 이것과 별개로 북오아시스에 바로 저장됩니다 (6번).

## 자주 묻는 것

- **책이 안 열리고 "다시 받기"가 나옵니다**: 임시 보관 책의 파일이 정리된 경우입니다. 서버에 연결된 상태라면 다시 받아 열립니다.
- **표지에 ☁가 붙어 있는데 열립니다**: 임시 보관(캐시)에 파일이 남아 있는 경우입니다. 계속 두려면 길게 눌러 "📌 서재에 보관"을 고르세요.
- **오디오북 받기가 시작되지 않습니다**: 받기 관리에서 "와이파이에서만 받기"가 켜져 있으면 와이파이를 기다립니다. ⚠️ 표시가 있으면 이유를 확인하고 🔁 다시 받기를 누르세요.
- **화면 가장자리를 밀었더니 앱이 닫힙니다**: 안드로이드는 가장자리 제스처를 화면 가운데 일부에서만 끌 수 있게 허용합니다. 화면 안쪽에서 시작해 넘기시거나, 휴대폰 설정에서 제스처 민감도를 낮추십시오.
- **암호가 걸린 PDF**는 열 수 없습니다.
