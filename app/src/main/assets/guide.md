# 사용 안내

OG Reader를 처음 쓰시는 분을 위한 짧은 안내입니다.

## 1. 서버 연결

1. 서재 화면 왼쪽 위 ☰ → **서버에서 책 찾기**
2. ⚙️ 서버 설정에서 서버를 추가합니다.
   - OPDS 주소: `https://<북오아시스 주소>/opds`
   - 아이디 / 비밀번호: 북오아시스 계정
   - 메타 API 주소: oasis-meta를 설치했다면 그 주소, 아니면 비워 둡니다
3. **연결 확인** → 저장

oasis-meta가 없어도 폴더 목록으로 모든 책을 받을 수 있습니다. 설치하면 시리즈별 표지 목록과 줄거리가 보입니다 (설정 › 메타 API 안내).

## 2. 책 받기

- **바로 읽기**: 서재에 담지 않고 임시로 받아 바로 엽니다. 임시 보관 한도를 넘으면 오래 안 본 책의 파일부터 정리되며, 읽은 위치와 하이라이트는 남습니다. 다시 열면 자동으로 다시 받습니다.
- **서재에 담기**: 계속 보관합니다. 임시로 받은 책은 서재에서 📌를 눌러 보관으로 바꿀 수 있습니다.
- 내 폰이나 구글 드라이브의 파일은 ☰ → **파일에서 가져오기**로 넣습니다.

지원 형식: EPUB · TXT · PDF · CBZ/ZIP(만화)

## 3. 책 읽기 (EPUB · TXT)

화면을 세로로 셋으로 나눠 생각하시면 됩니다.

| 누르는 곳 | 동작 |
|---|---|
| 왼쪽 30% | 이전 쪽 |
| 가운데 | 상단바 보이기 / 숨기기 |
| 오른쪽 30% | 다음 쪽 |
| 맨 위 장 제목 줄 | 상단바 보이기 (어디서나) |

- 좌우로 밀어도 넘어갑니다. 넘김 효과가 **종이 말림**이면 모서리가 손가락을 따라 말리고, 중간에 놓으면 넘어가거나 제자리로 돌아갑니다.
- **그림**: 그림 위를 짧게 누르면 다른 곳과 똑같이 쪽을 넘기거나 상단바를 띄웁니다. 그림을 크게 보려면 **길게 누르십시오.**
- 그림이 화면을 거의 다 덮은 쪽에서도 가운데를 누르면 상단바가 뜹니다.
- 글자를 길게 눌러 선택하면 하이라이트·메모를 남길 수 있습니다.
- 가운데를 눌러 상단바를 띄우면 아래에 얇은 슬라이더가 함께 뜹니다. 끌면 장 제목과 %가 보이고, 놓으면 그 위치로 이동합니다.
- 블루투스 페이지 리모컨·키보드: →·↓·Page Down·Space는 다음 쪽, ←·↑·Page Up은 이전 쪽입니다. 볼륨 버튼은 설정 › 리모컨 · 키보드에서 켤 수 있습니다.
- 하이라이트는 마크다운으로 내보낼 수 있습니다: ⋮ › 하이라이트 › 내보내기, 또는 서재에서 책을 길게 눌러 "하이라이트 내보내기". 공유하거나 .md 파일로 저장합니다.
- 모든 하이라이트를 한 번에 보관하려면 ☰ › 하이라이트 › ⋮ › "전체 내보내기 (JSON)"을 누릅니다.

### 상단바

| 버튼 | 내용 |
|---|---|
| ☀️ | 화면 밝기 |
| 가 | 글자 크기 · 줄 간격 · 여백 · 배경 색 |
| ✒️ | 글꼴 (내 글꼴 파일 추가 가능) |
| ⋮ | 목차, 하이라이트, 넘김 효과, 스크롤로 보기 등 |

- 글꼴·크기·여백·배경 같은 설정은 **책마다 따로 기억**됩니다. 마음에 드는 설정은 ⋮ → **이 책 설정을 기본값으로**를 누르면 다른 책에도 적용됩니다.
- 상단바는 2초 뒤 저절로 숨고, 숨어 있는 동안에는 화면 가장자리 가운데 부분의 뒤로 가기 제스처가 꺼집니다 (쪽 넘김과 겹치지 않도록). 나가려면 가운데를 눌러 상단바를 띄운 뒤 ← 를 누르십시오.

## 4. 만화 · PDF

- 왼쪽/오른쪽 30%를 누르거나 밀어서 넘깁니다. 가운데를 누르면 상단바가 뜹니다.
- 두 손가락으로 벌리거나 두 번 누르면 확대됩니다. 확대된 상태에서 두 번 누르면 원래대로 돌아옵니다.
- 폴드를 펼치면 맞쪽(두 쪽)으로 보입니다.
- ⋮ 메뉴: 세로 스크롤(웹툰), 오른쪽→왼쪽 넘기기(일본 만화), 넘김 효과, 화면 밝기 등

## 5. 서재

- 책을 길게 누르거나 ⋮을 누르면 책 정보, 이름 바꾸기, 보관(📌), 삭제가 나옵니다.
- **⤢ 크기**로 표지 타일 크기를 조절합니다.

## 6. 설정

- **화면**: 앱 전체 밝게 / 어둡게 / 시스템 따라가기
- **바로 읽기**: 임시 보관 한도 (기본 2GB, 최대 50GB)
- **백업**: 책·읽은 위치·하이라이트·설정을 zip 하나로 저장합니다 (실험적 기능). 서버 비밀번호는 백업되지 않습니다.
- **진행 동기화**: 7번 "진행 동기화"를 보세요.
- **업데이트**: 새 버전이 나오면 서재 위에 알림 띠가 뜹니다 (서재를 열 때 확인). "업데이트"를 누르면 받아서 설치 화면을 엽니다. 처음 한 번은 "이 출처 허용"을 켜야 합니다. 설정 › 정보 › "업데이트 확인"으로 바로 확인할 수도 있습니다.

## 7. 진행 동기화

북오아시스 서버를 거쳐 **읽은 위치**를 기기끼리 맞춥니다.

**준비**: 북오아시스 웹 → 계정 메뉴 → KOReader 동기화에서 동기화 비밀번호를 정한 뒤, 앱의 설정 › 북오아시스 진행 동기화에서 연결합니다.

| 무엇을 | 상대 | EPUB·TXT | 만화·PDF |
|---|---|---|---|
| 읽은 위치 | 다른 OG Reader | ✅ 장 안 위치까지 | ✅ 쪽 |
| 읽은 위치 | KOReader 기기 | △ 장 시작까지 | ✅ 쪽 |
| 읽은 위치 | 북오아시스 웹 | ❌ | ✅ 쪽 (웹 "최근 읽은 도서"에도 뜸) |
| 하이라이트·메모·설정 | 어디든 | ❌ (백업으로 옮기세요) | ❌ |
| 서재 목록(어떤 책이 있는지) | 어디든 | ❌ | ❌ |

- **언제 올리나**: 그 책을 1분 이상 읽었거나 2쪽 이상 넘긴 뒤, 잠깐 멈췄을 때·앱을 내렸을 때·책을 닫을 때.
- **언제 받나**: 책을 열 때. 다른 기기에서 더 읽었으면 그 위치로 갈지 물어봅니다. 서재에는 그런 책에 "⇄ %"가 붙습니다.
- **같은 책이어야 합니다**: 책은 파일 내용으로 구분하므로 같은 파일을 받은 기기끼리만 맞춰집니다.
- 동기화 기능이 생기기 전에 받은 만화는 북오아시스 웹과 안 맞을 수 있습니다. 한 번 다시 받으면 됩니다.

## 자주 묻는 것

- **책이 안 열리고 "다시 받기"가 나옵니다**: 임시 보관 책의 파일이 정리된 경우입니다. 서버에 연결된 상태라면 다시 받아 열립니다.
- **화면 가장자리를 밀었더니 앱이 닫힙니다**: 안드로이드는 가장자리 제스처를 화면 가운데 일부 구간에서만 끌 수 있게 허용합니다. 위·아래쪽 가장자리에서 시작한 스와이프는 여전히 뒤로 가기가 됩니다. 화면 안쪽에서 시작해 넘기시거나, 휴대폰 설정에서 제스처 민감도를 낮추십시오.
- **암호가 걸린 PDF**는 열 수 없습니다.
