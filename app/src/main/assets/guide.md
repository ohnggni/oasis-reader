# 자세한 사용법

## 1. 서버 연결

1. 서재 ☰ → **서버에서 책 가져오기** → ⚙️ 서버 설정 → ➕
2. **종류**를 고릅니다.
   - **일반 / 성인**: 책 서버(OPDS). 주소 `https://<서버 주소>/opds`, 서버 계정
   - **오디오북**: 북오아시스 주소와 계정
   - **🗄️ 파일 서버**: WebDAV · SFTP · SMB · FTPS · FTP. 주소는 시작할 폴더까지(예: `smb://192.168.0.10/공유폴더/책`)
3. **연결 확인** → 저장

- 일반 FTP는 암호화되지 않으니 집 안에서만 쓰세요.
- 메타 API(oasis-meta)가 있으면 그 주소도 넣습니다. 시리즈별 표지 목록 · 줄거리 · 필터가 생깁니다. 없어도 폴더 목록으로 다 받을 수 있습니다.

## 2. 책 가져오기

| 방법 | 설명 |
|---|---|
| **바로 읽기** | 임시로 받아 바로 엽니다. 공간이 모자라면 오래 안 본 파일부터 정리됩니다(위치 · 하이라이트는 남음) |
| **서재에 담기** | 계속 보관합니다. 앱을 닫아도 받고, 끊기면 이어 받습니다 |
| ☰ → **파일에서 책 가져오기** | 내 폰 · 구글 드라이브의 파일 |
| ☰ → **폴더에서 책 가져오기** | 하위 폴더까지 한 번에. 폴더마다 📚 컬렉션으로 묶을 수 있습니다 |
| 다른 앱에서 **공유 › OG Reader** | 책 파일(EPUB · CBZ/ZIP · PDF · TXT), 여러 개도 됩니다 |

- 받는 동안 아래 카드에 진행률이 나옵니다. 다 받으면 **📚 서재에서 보기**로 그 책에 바로 갑니다.
- 서버 화면 상단바의 🏠는 어디서든 서재로 돌아갑니다.
- **⬇️ 이 폴더 모두 담기**: 폴더의 책을 한 번에 담습니다.
- **⭐ 폴더 즐겨찾기**: 폴더 화면의 ⭐. 서버 첫 화면에 칩으로 나옵니다. 🕘는 지난번 폴더입니다.
- 필터 줄: 카테고리 · 형식 · ⭐ 프리셋 · 정렬 · 🔲 타일 / 📃 목록 · 📐 크기
- **🗄️ 파일 서버**: 책을 누르면 바로 읽기, ⬇️는 서재에 담기. 길게 눌러 여러 개를 고릅니다.
- 임시로 받은 책을 계속 두려면 책 메뉴에서 **📌 서재에 보관**.

## 3. 서재

- **표지 표시**: 오른쪽 아래 채운 원 ⬇ = 폰에 있음, 빈 원 ☁ = 서버에만 있거나 임시 보관. 왼쪽 아래 ⋮ = 책 메뉴
- **종류 탭**: 전체 · 📖 책 · 🖼️ 만화 · 📄 PDF · 🎧 오디오북. 보기 · 크기 · 정렬은 탭마다 따로 기억합니다.
- **🔍 찾기**: 제목 · 저자 · 컬렉션 이름. **초성**도 됩니다(ㅇㅍㅅ → 원피스).
- **정렬**: 읽은 날짜 · 추가한 날짜 · 제목 · 저자 · 진행률 · 종류
- **빠른 이동**: 오른쪽 가장자리를 끌면 빠르게 움직입니다. ⬆️는 맨 위로.
- **📚 컬렉션**: 내 책장입니다. 📚 칩에서 만들고, 책 메뉴 › 컬렉션에 넣기. 한 책을 여러 곳에 넣을 수 있습니다.
- **묶어 보기**(보기 칩)
  - 📚 컬렉션별: 컬렉션이 폴더로 보입니다.
  - 🔗 컬렉션 + 시리즈별: 컬렉션에 없는 책도 같은 시리즈끼리 자동으로 묶습니다. 묶음 ⋮ › 컬렉션으로 만들기 / 풀기
- **여러 권 고르기**: 책을 길게 누릅니다. 아래 막대에서 지우기 · 폰에서 지우기 · 컬렉션에 넣기 · 보관 / 임시로 · 다 읽음. 폴더를 길게 누르면 안의 책이 모두 골라집니다.
- **컬렉션 지우기**: 컬렉션만 지우거나, 안의 책도 함께 지웁니다.
- **☰ 메뉴**: 책 가져오기 · 하이라이트 · 독후감 · 독서 통계 · 📦 보관함 관리 · ⬇️ 받기 관리

## 4. 책 읽기 (EPUB · TXT)

| 누르는 곳 | 동작 |
|---|---|
| 왼쪽 30% | 이전 쪽 |
| 가운데 | 상단바 보이기 / 숨기기 |
| 오른쪽 30% | 다음 쪽 |

- 좌우로 밀어도 넘어갑니다.
- **글자를 길게 눌러 고르면** 하이라이트 · 메모 · 찾아보기(사전 · 번역 · 검색)
- **그림**을 길게 누르면 크게 봅니다.
- **각주** 번호를 누르면 아래에 내용이 뜹니다. 링크로 이동한 뒤에는 "↩️ 원래 보던 곳으로".
- 상단바를 띄우면 아래에 위치 슬라이더가 나옵니다.
- 리모컨 · 키보드: → ↓ Page Down Space = 다음 쪽, ← ↑ Page Up = 이전 쪽. 볼륨 버튼은 설정에서 켭니다.
- 상단바가 숨어 있을 때는 가장자리 뒤로 가기 제스처가 꺼집니다. 가운데를 눌러 상단바를 띄운 뒤 ←.

### 상단바

| 버튼 | 내용 |
|---|---|
| ☀️ 화면 | 밝기, 배경, 화면 켜짐 유지, 상단바 자동 숨김 |
| 가 글자 | 글꼴(내 글꼴 추가), 크기 · 굵기 · 줄간격 |
| ▤ 쪽 | 넘기기 / 스크롤, 넘김 효과 · 속도, 여백 |
| ☰ 이동 | 목차, 본문 검색, 소리 내 읽기, 책갈피, 하이라이트, 다 읽음, 다음 권 |

- 설정은 **책마다 따로** 기억합니다. **기본값으로 저장**을 누르면 다른 책에도 적용됩니다.
- **책갈피**: 상단바의 책갈피 표시를 누릅니다. 목록은 ☰ 이동 › 책갈피.
- **소리 내 읽기**: ☰ 이동 › 소리 내 읽기. 읽는 문장을 따라가며 쪽이 저절로 넘어갑니다. 화면을 꺼도 계속 읽습니다. 막대에서 빠르기 · 🌙 수면 타이머 · 🎙 목소리.
- **하이라이트 모아 보기**: 서재 ☰ › 하이라이트. 책별 내보내기(마크다운) · 복사 · 지우기.
- 책을 지워도 하이라이트 · 메모는 남길 수 있고, 같은 책을 다시 받으면 이어집니다.

## 5. 만화 · PDF

- 왼쪽 / 오른쪽을 누르거나 밀어서 넘깁니다. 두 손가락이나 두 번 누르기로 확대.
- 상단바 ▣ 보기: 책처럼 넘기기 / 세로 스크롤(웹툰), 오른쪽→왼쪽, 맞쪽
- 처음 여는 만화의 보기는 설정 › 읽기 기본값 › **만화 · PDF**에서 정합니다. 웹툰을 주로 보면 세로 스크롤로.
- 폴드를 펼치면 두 쪽으로 보입니다.

### 다음 권 · 있던 폴더
- 마지막 쪽에 **다음 권 ▶** 카드가 뜹니다(웹툰은 맨 끝 버튼). 서버에만 있으면 받아서 엽니다.
- 같은 컬렉션에서 먼저 찾고, 없으면 받았던 서버 폴더 · 시리즈에서 찾습니다.
- ☰ 이동 또는 책 메뉴의 **📂 있던 폴더 열기**로 받은 곳을 다시 엽니다.

### 상태바 · 내비게이션 바 숨기기
- 설정 › 읽기 기본값에서 켭니다. 읽는 화면에서만 숨습니다.
- 상태바를 숨기면 위쪽 줄에 장 제목 · 시계 · 배터리가 나옵니다. 책마다 따로 끄고 켤 수 있습니다.
- 숨긴 바는 화면 가장자리에서 쓸면 잠깐 나옵니다.

## 6. 오디오북 (북오아시스)

- 서버 종류를 **오디오북**으로 추가한 뒤 ☰ → 서버에서 책 가져오기에서 고릅니다.
- 검색창 옆 칩에서 제목 · 작가 · 주제 중 찾을 곳을 고릅니다.
- 책을 누르면 트랙 목록. **이어 듣기**는 저장된 위치부터.
- **플레이어**: ⏮ · 15초 뒤로 · ⏯ · 30초 앞으로 · ⏭, 속도, 🌙 수면 타이머, 음량. 제목 아래 줄을 누르면 장 목록이 뜹니다.
- 화면을 꺼도 들리고, 알림창 · 잠금 화면 · 이어폰으로 조작합니다.
- 들은 위치는 서버에 저장돼 웹이나 다른 기기와 이어집니다.
- 들은 오디오북은 서재에 저절로 담깁니다.

### 폰에 받기
- 상세 화면의 **⬇️ 폰에 받기**(책 전체) 또는 트랙 옆 ⬇️
- **⬇️ 받기 관리**(서재 ☰): 받는 중인 것을 모아 봅니다. ⏸️ · ▶️ · ✖️, **📶 와이파이에서만 받기**
- 일부만 받았으면 나머지는 스트리밍으로 듣습니다.

## 6-1. 소장 오디오북 (파일 서버 · 폰 폴더)

- **파일 서버**: 폴더 화면 위의 **🎧 오디오북** → ☁️ 서버에서 바로 듣기 / ⬇️ 폰에 받기
- **폰 폴더**: 서재 ☰ › **폴더에서 오디오북 가져오기** → 📂 그대로 듣기 / 📥 앱 안으로 복사
- **폴더 규칙**: 소리 파일이 든 폴더 = 한 권. 트랙은 파일 이름 순서(01, 02 …). `CD1` · `Disc 2` 같은 하위 폴더는 한 권으로 합칩니다.
- **정보**: `metadata.json` → `*.nfo` → 폴더 이름 순서로 제목 · 저자를 읽습니다. 표지는 `cover` · `folder` 그림.
- m4b 하나짜리 책은 파일 안의 장을 보여 줍니다.

### 책갈피 (오디오북)
- 재생 화면 **🔖 책갈피** › 지금 자리에 남기기 / 방금 들은 30초 남기기. 메모를 적을 수 있습니다.
- 책갈피를 누르면 **▶ 여기부터 듣기**.
- 서재 ☰ › 하이라이트에 책의 하이라이트와 함께 모입니다.

## 6-2. 독후감

- 쓰기: 책 메뉴 › **📝 독후감**. 별점과 글, 자동 저장.
- 모아 보기: 서재 ☰ › **📝 독후감**
- 다른 앱에서 쓴 글: **공유 › OG Reader** → 책 고르기. 글 파일(.txt · .md)도 가져옵니다.
- **🖍️ 하이라이트 넣기**: 그 책의 하이라이트를 인용문으로 넣습니다.
- 📤 공유, 마크다운 파일로 저장(하이라이트 포함)
- 책을 지워도 독후감은 남습니다.

## 6-3. 독서 습관 알림

- 설정 › 독서 습관에서 시각과 요일을 정합니다.
- 알림을 누르면 마지막에 읽던 책이 바로 열립니다.
- "오늘 이미 읽었으면 알리지 않기"를 켤 수 있습니다.
- 폰이 절전 중이면 몇 분 늦을 수 있습니다.

## 6-4. 테마 · 글자 크기 · 아이콘

설정 › 화면에 있습니다.

- **테마**: 시스템 · 라이트 · 다크, 그리고 읽기 테마(종이 · 흰색 · 세피아 · 회색 · 연두 · 분홍 · 밤 · 남색 · 검정)를 서재와 메뉴에도 입힙니다.
- 읽기 테마가 "자동"이면 읽는 화면도 앱 테마를 따라갑니다. 책마다 고른 테마는 그대로입니다.
- **E-INK (흑백)**: 전자잉크 화면용. 흑백만 쓰고 쪽 넘김 효과 같은 움직임을 끕니다.
- **글자 크기**: 서재 · 메뉴 · 설정의 글자 5단계. 책 본문 크기와는 별개입니다.
- **아이콘**: 단색(선 아이콘) ↔ 이모지

## 7. 독서 통계

서재 ☰ › 독서 통계. 오늘 · 연속 일수 · 이번 달 · 올해 읽은 권수, 총 시간(🎧 따로), 달력, 책별 시간.

## 8. 설정

- **읽기**: 읽기 기본값, 찾아보기 앱, 소리 내 읽기 목소리
- **저장 공간 · 📦 보관함 관리**: 책을 📱 폰에 있음 / ☁️ 서버에만으로 나눠 보고, 여러 권을 골라 폰에서 지우기 · 받기 · 보관 / 임시로
- **바로 읽기**: 임시 보관 한도(기본 2GB)
- **백업 · 기기 변경**: 서재 · 위치 · 하이라이트 · 독후감 · 설정을 zip 하나로. 서버에서 받은 책은 새 폰에서 다시 받습니다. 서버 비밀번호는 들어가지 않습니다.
- **받은 파일 보호**: 받은 파일은 앱 전용 공간에 있고, 오디오북은 암호화해 둡니다.
- **업데이트**: 새 버전이 나오면 서재 위에 알림 띠가 뜹니다.

## 9. 진행 동기화

북오아시스 서버를 거쳐 **읽은 위치**를 기기끼리 맞춥니다.

**준비**: 북오아시스 웹 › 계정 › KOReader 동기화에서 비밀번호를 정한 뒤, 앱 설정 › 읽은 위치 동기화에서 연결합니다.

| 상대 | EPUB · TXT | 만화 · PDF |
|---|---|---|
| 다른 OG Reader | ✅ 장 안 위치까지 | ✅ 쪽 |
| KOReader 기기 | △ 장 시작까지 | ✅ 쪽 |
| 북오아시스 웹 | ❌ | ✅ 쪽 |

- 하이라이트 · 메모 · 설정은 동기화되지 않습니다(백업으로 옮기세요).
- 책을 열 때 다른 기기에서 더 읽었으면 그 위치로 갈지 묻습니다.
- 같은 파일을 받은 기기끼리만 맞춰집니다.

## 자주 묻는 것

- **"다시 받기"가 나옵니다**: 임시 보관 파일이 정리된 경우입니다. 서버에 연결돼 있으면 다시 받아 열립니다.
- **☁ 표시인데 열립니다**: 임시 보관에 파일이 남아 있는 경우입니다. 계속 두려면 **📌 서재에 보관**.
- **오디오북 받기가 시작되지 않습니다**: "와이파이에서만 받기"가 켜져 있는지 보세요. ⚠️가 있으면 이유를 확인하고 🔁 다시 받기.
- **가장자리를 밀었더니 앱이 닫힙니다**: 화면 안쪽에서 시작해 넘기거나, 폰 설정에서 제스처 민감도를 낮추세요.
- **암호가 걸린 PDF**는 열 수 없습니다.
