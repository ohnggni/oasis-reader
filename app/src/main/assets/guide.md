# 사용 안내

OG Reader를 처음 쓰시는 분을 위한 짧은 안내입니다.

## 1. 서버 연결

1. 서재 화면 왼쪽 위 ☰ → **서버에서 책 찾기**
2. ⚙️ 서버 설정에서 서버를 추가합니다.
   - OPDS 주소: `https://<서버 주소>/opds`
   - 아이디 / 비밀번호: 서버 계정
   - 메타 API 주소: oasis-meta를 설치했다면 그 주소, 아니면 비워 둡니다
3. **연결 확인** → 저장

oasis-meta가 없어도 폴더 목록으로 모든 책을 받을 수 있습니다. 설치하면 시리즈별 표지 목록과 줄거리가 보입니다 (설정 › 메타 API 안내).

## 2. 책 받기

- **바로 읽기**: 서재에 담지 않고 임시로 받아 바로 엽니다. 임시 보관 한도를 넘으면 오래 안 본 책의 파일부터 정리되며, 읽은 위치와 하이라이트는 남습니다. 다시 열면 자동으로 다시 받습니다.
- **서재에 담기**: 계속 보관합니다. 임시로 받은 책은 서재에서 📌를 눌러 보관으로 바꿀 수 있습니다.
- 내 폰이나 구글 드라이브의 파일은 ☰ → **파일에서 가져오기**로 넣습니다.
- 시리즈별 보기(메타 API가 있을 때): **카테고리**와 **형식**(EPUB·TXT·PDF·만화)을 여러 개 고를 수 있고, 둘 다 맞는 것만 보입니다. 자주 쓰는 조합은 **★ 프리셋**으로 저장해 두고 한 번에 고릅니다 (서버 설정에서도 만들고 고칠 수 있습니다).

지원 형식: EPUB · TXT · PDF · CBZ/ZIP(만화)

## 3. 책 읽기 (EPUB · TXT)

화면을 세로로 셋으로 나눠 생각하시면 됩니다.

| 누르는 곳 | 동작 |
|---|---|
| 왼쪽 30% | 이전 쪽 |
| 가운데 | 상단바 보이기 / 숨기기 |
| 오른쪽 30% | 다음 쪽 |
| 맨 위 장 제목 줄 | 상단바 보이기 (어디서나) |

- 좌우로 밀어도 넘어갑니다. 넘김 효과가 **종이 말림**이면 모서리가 손가락을 따라 말리고, 중간에 놓으면 넘어가거나 제자리로 돌아갑니다.
- **그림**: 그림 위를 짧게 누르면 다른 곳과 똑같이 쪽을 넘기거나 상단바를 띄웁니다. 그림을 크게 보려면 **길게 누르십시오.**
- 그림이 화면을 거의 다 덮은 쪽에서도 가운데를 누르면 상단바가 뜹니다.
- 글자를 길게 눌러 선택하면 하이라이트·메모를 남길 수 있습니다.
- 고른 글자 옆 막대의 **찾아보기**를 누르면 번역·사전 앱(파파고, 구글 번역 등), 네이버 사전, 위키백과로 바로 찾아볼 수 있습니다.
- 찾아보기에 나오는 앱과 순서는 설정 › 읽기 › **찾아보기 앱**에서 정합니다.
- **각주**: 본문의 각주 번호를 누르면 아래에 각주 내용이 떠오릅니다. 바깥을 누르면 닫힙니다.
- 가운데를 눌러 상단바를 띄우면 아래에 얇은 슬라이더가 함께 뜹니다. 끌면 장 제목과 %가 보이고, 놓으면 그 위치로 이동합니다.
- 블루투스 페이지 리모컨·키보드: →·↓·Page Down·Space는 다음 쪽, ←·↑·Page Up은 이전 쪽입니다. 볼륨 버튼은 설정 › 리모컨 · 키보드에서 켤 수 있습니다.
- 하이라이트는 마크다운으로 내보낼 수 있습니다: ☰ 이동 › 하이라이트 내보내기, 또는 서재에서 책을 길게 눌러 "하이라이트 내보내기". 공유하거나 .md 파일로 저장합니다.
- 모든 하이라이트를 한 번에 보관하려면 ☰ › 하이라이트 › ⋮ › "전체 내보내기 (JSON)"을 누릅니다.

### 상단바

| 버튼 | 내용 |
|---|---|
| ☀️ 화면 | 밝기, 배경, 화면 켜짐 유지, 상단바 자동 숨김 |
| 가 글자 | 글꼴(내 글꼴 추가), 크기·굵기·줄간격, 출판사 스타일 |
| ▤ 쪽 | 책처럼 넘기기 / 스크롤, 넘김 효과·속도, 여백 |
| ☰ 이동 | 목차, 본문 검색, 소리 내 읽기, 책갈피, 이 책의 하이라이트, 하이라이트 내보내기, 다 읽음 |

- 글꼴·크기·여백·배경·넘김 설정은 **책마다 따로 기억**됩니다. 글자·쪽 묶음 맨 아래의 **기본값으로 저장**을 누르면 다른 책에도 적용되고, **되돌리기**를 누르면 이 책도 기본 설정을 따릅니다.
- 기본값 자체는 설정 › 읽기 › **읽기 기본값**에서 정합니다.
- **책갈피**: 상단바 왼쪽의 책갈피 표시를 누르면 지금 쪽이 저장되고, 다시 누르면 지워집니다. 목록은 ☰ 이동 › 책갈피.
- **본문 검색**: ☰ 이동 › 본문 검색. 띄어쓰기 개수와 대소문자는 가리지 않습니다. 결과를 누르면 그 자리로 가서 찾은 낱말을 몇 초 동안 표시합니다.
- **소리 내 읽기**: ☰ 이동 › 소리 내 읽기. 음성 엔진이 지금 쪽의 첫 문장부터 읽고, 읽는 문장에 옅은 색이 따라가며 쪽과 장이 저절로 넘어갑니다. 각주 번호는 읽지 않습니다.
  - 아래 막대(반투명, 끌어서 옮길 수 있음): ⏮ 이전 문장 · ⏸ 일시정지 · ⏭ 다음 문장 · 빠르기(0.5~2배) · 🌙 수면 타이머(15~60분, 이 장 끝에서) · 🎙 목소리 · ✕ 끝내기
  - 화면을 끄거나 다른 앱으로 가도 계속 읽습니다. 알림창·잠금 화면의 재생 컨트롤과 이어폰·블루투스 버튼으로도 멈추고 넘깁니다. 전화가 오거나 다른 앱이 소리를 내면 멈춥니다.
  - 화면이 꺼진 동안 다음 장으로 넘어가면, 다시 화면을 켰을 때 읽고 있는 자리로 쪽이 따라옵니다.
  - 🎙 목소리: 음성 엔진(삼성·구글 등)과 목소리를 고르고 ▶ 듣기로 미리 들어 봅니다. 삼성 엔진의 자연스러운 목소리를 쓰려면 엔진에서 '삼성 텍스트 음성 변환'을 고르세요. 설정 › 읽기 › 소리 내 읽기 목소리에서도 바꿀 수 있습니다.
- **책 디자인 사용**: 켜면 책에 들어 있는 제목 크기·가운데 정렬, 문단 들여쓰기·간격 같은 모양을 따릅니다. 끄면 앱의 단순한 모양(문단 사이 간격, 제목 왼쪽 정렬)으로 보입니다. 글꼴·글자 크기·색은 어느 쪽이든 앱 설정이 우선입니다.
- 상단바는 2초 뒤 저절로 숨고, 숨어 있는 동안에는 화면 가장자리 가운데 부분의 뒤로 가기 제스처가 꺼집니다 (쪽 넘김과 겹치지 않도록). 나가려면 가운데를 눌러 상단바를 띄운 뒤 ← 를 누르십시오.

## 4. 만화 · PDF

- 왼쪽/오른쪽 30%를 누르거나 밀어서 넘깁니다. 가운데를 누르면 상단바가 뜹니다.
- 두 손가락으로 벌리거나 두 번 누르면 확대됩니다. 확대된 상태에서 두 번 누르면 원래대로 돌아옵니다.
- 폴드를 펼치면 맞쪽(두 쪽)으로 보입니다.
- 상단바 네 버튼: ☀️ 화면(밝기, 화면 켜짐, 바 자동 숨김) · ▣ 보기(책처럼 넘기기/세로 스크롤(웹툰), 오른쪽→왼쪽(일본 만화), 맞쪽) · ⇆ 넘김(효과·속도) · ☰ 이동(처음부터, 다 읽음)

## 4-1. 오디오북 (북오아시스)

- 처음 한 번: 설정 › 서버 › ➕ 에서 종류를 **오디오북**으로 고르고 북오아시스 주소와 계정을 넣습니다. 그다음 서재 ☰ → **서버에서 책 찾기**에서 그 서버를 고르면 오디오북 목록이 나옵니다 (북오아시스 웹에 로그인해서 가져옵니다).
- 책을 누르면 트랙 목록이 나오고, **이어 듣기**는 북오아시스에 저장된 위치부터 재생합니다. 트랙을 누르면 그 트랙 처음부터 듣습니다.
- 플레이어: ⏮ 이전 트랙 · ↺15 15초 뒤로 · ⏯ · 30↻ 30초 앞으로 · ⏭ 다음 트랙, 속도, 🌙 수면 타이머. 화면을 끄거나 다른 앱을 써도 계속 들리고, 알림창·잠금 화면·이어폰 버튼으로 조작합니다.
- 들은 위치는 15초마다, 그리고 멈출 때 북오아시스에 저장됩니다. 웹에서 이어 들을 수 있습니다.
- 들은 오디오북은 서재에 🎧 표시로 담깁니다 (상세 화면의 "📚 서재에 담기"로 미리 담을 수도 있습니다). 서재에서 누르면 들은 자리부터 이어 듣습니다. 서재에서 지워도 서버의 오디오북과 들은 위치는 그대로입니다.
- **오프라인**: 서재에서 오디오북을 길게 눌러 "⬇️ 폰에 받기"(또는 상세 화면의 "폰에 받기"). 받은 책은 표지에 ⬇가 붙고 인터넷 없이 들을 수 있습니다. 받지 않은 책은 ☁️(스트리밍)로 표시됩니다.
- 서재 아래 재생 막대: 누르면 플레이어, ⏸/▶, ✕는 재생을 끝내고 막대를 닫습니다.

## 5. 서재

- 책을 길게 누르거나 ⋮을 누르면 책 정보, 이름 바꾸기, 보관(📌), 삭제가 나옵니다.
- **⤢ 크기**로 표지 타일 크기를 조절합니다.

## 6. 설정

- **화면**: 앱 전체 밝게 / 어둡게 / 시스템 따라가기
- **바로 읽기**: 임시 보관 한도 (기본 2GB, 최대 50GB)
- **백업**: 책·읽은 위치·하이라이트·설정을 zip 하나로 저장합니다 (실험적 기능). 서버 비밀번호는 백업되지 않습니다.
- **진행 동기화**: 7번 "진행 동기화"를 보세요.
- **업데이트**: 새 버전이 나오면 서재 위에 알림 띠가 뜹니다 (서재를 열 때 확인). "업데이트"를 누르면 받아서 설치 화면을 엽니다. 처음 한 번은 "이 출처 허용"을 켜야 합니다. 설정 › 정보 › "업데이트 확인"으로 바로 확인할 수도 있습니다.

## 7. 진행 동기화

북오아시스 서버를 거쳐 **읽은 위치**를 기기끼리 맞춥니다.

**준비**: 북오아시스 웹 → 계정 메뉴 → KOReader 동기화에서 동기화 비밀번호를 정한 뒤, 앱의 설정 › 읽은 위치 동기화에서 연결합니다.

| 무엇을 | 상대 | EPUB·TXT | 만화·PDF |
|---|---|---|---|
| 읽은 위치 | 다른 OG Reader | ✅ 장 안 위치까지 | ✅ 쪽 |
| 읽은 위치 | KOReader 기기 | △ 장 시작까지 | ✅ 쪽 |
| 읽은 위치 | 북오아시스 웹 | ❌ | ✅ 쪽 (웹 "최근 읽은 도서"에도 뜸) |
| 하이라이트·메모·설정 | 어디든 | ❌ (백업으로 옮기세요) | ❌ |
| 서재 목록(어떤 책이 있는지) | 어디든 | ❌ | ❌ |

- **언제 올리나**: 그 책을 1분 이상 읽었거나 2쪽 이상 넘긴 뒤, 잠깐 멈췄을 때·앱을 내렸을 때·책을 닫을 때.
- **언제 받나**: 책을 열 때. 다른 기기에서 더 읽었으면 그 위치로 갈지 물어봅니다. 서재에는 그런 책에 "⇄ %"가 붙습니다.
- **같은 책이어야 합니다**: 책은 파일 내용으로 구분하므로 같은 파일을 받은 기기끼리만 맞춰집니다.
- 동기화 기능이 생기기 전에 받은 만화는 북오아시스 웹과 안 맞을 수 있습니다. 한 번 다시 받으면 됩니다.

## 자주 묻는 것

- **책이 안 열리고 "다시 받기"가 나옵니다**: 임시 보관 책의 파일이 정리된 경우입니다. 서버에 연결된 상태라면 다시 받아 열립니다.
- **화면 가장자리를 밀었더니 앱이 닫힙니다**: 안드로이드는 가장자리 제스처를 화면 가운데 일부 구간에서만 끌 수 있게 허용합니다. 위·아래쪽 가장자리에서 시작한 스와이프는 여전히 뒤로 가기가 됩니다. 화면 안쪽에서 시작해 넘기시거나, 휴대폰 설정에서 제스처 민감도를 낮추십시오.
- **암호가 걸린 PDF**는 열 수 없습니다.
