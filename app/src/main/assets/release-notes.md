  - 가운데 **제목 · 장(트랙) 줄을 누르면 목록이 떠서** 바로 옮겨 갑니다. 화면 아래에 길게 깔리던 목록은 이 목록으로 옮겼습니다
  - **🔈 음량 슬라이더**(폰의 미디어 음량, 볼륨 버튼과 같이 움직임)

## 1.4
- **🎧 소장 오디오북 가져오기**: 🗄️ 파일 서버 폴더 화면의 "🎧 오디오북", 또는 서재 ☰ › "폰 폴더에서 오디오북 가져오기". 소리 파일(mp3 · m4a · m4b · ogg · flac …)이 든 폴더 하나가 한 권이 되어 서재에 들어갑니다
  - 파일 서버는 **☁️ 서버에서 바로 듣기 / ⬇️ 폰에 받기**, 폰 폴더는 **📂 폴더에서 그대로 / 📥 앱 안으로 복사**를 고릅니다
  - 제목 · 저자 · 낭독자 · 표지를 metadata.json(Audiobookshelf 형식) · .nfo · 폴더 안 표지 그림에서 읽습니다. CD1 · Disc 2 같은 하위 폴더는 한 권으로 합칩니다
  - **장 표시**: m4b 안의 장(챕터)과 metadata.json의 장을 플레이어에 보여 주고, ⏮ ⏭가 장 단위로 움직입니다
- **읽기 기본값 › 만화 · PDF**: 보기(자동 · 책처럼 넘기기 · 세로 스크롤), 방향, 맞쪽, 폭. 기본값 "스크롤"이 만화에 적용되지 않던 문제
- 웹툰 스크롤: **"다음 권"이 맨 끝 "— 끝 —" 아래 버튼으로** — 너무 일찍 뜨거나 맨 끝에서 사라지던 카드 대신
- 서재의 컬렉션 폴더에서 책을 읽고 돌아오면 **그 폴더, 그 위치로** 돌아옵니다(전에는 전체 서재로 나감)

## 1.3

- 서버 화면 위쪽을 줄였습니다: 시리즈별 / 폴더별 탭, 낮은 검색창, 개수와 🔲·📐를 한 줄로
- 서재 표지 아래 제목이 항상 이모지 바로 옆에서 시작합니다
- 받기 관리: 받는 중인 것만 보이고(다 받은 오디오북은 📦 보관함 관리로), ⚡ 바로 읽기 받기와 ✅ 최근 받음(하루)도 보입니다
- **🗄️ 파일 서버에서 책 가져오기**: WebDAV · SFTP · SMB(윈도 공유·NAS) · FTPS · FTP. 서버 설정 › 종류 › 🗄️ 파일 서버. 폴더를 둘러보고 바로 읽기·서재에 담기, 여러 개·폴더째 담기(하위 폴더, 폴더 이름으로 컬렉션), 백그라운드 이어 받기, 다음 권·있던 폴더 열기
- 🔗 자동 시리즈 묶음: 묶음 ⋮ › **🔓 이 묶음 풀기**(보기 메뉴에서 다시 묶기)
- 상태바 숨기기를 켠 뒤 서재로 돌아오면 위쪽이 상태바와 겹치던 문제(일부 기기)

첫 정식 버전입니다. 0.1.x 동안 만든 기능을 정리했습니다.
- 전자책(EPUB·TXT)·만화(CBZ·ZIP)·PDF 읽기, 북오아시스 오디오북 듣기
- OPDS 서버에서 바로 읽기·서재에 담기, 북오아시스 메타 API(oasis-meta)로 시리즈별 보기·줄거리·필터
- 서재: 컬렉션, 종류·읽음 상태 필터, 종류별 정렬, 폰에 받음(⬇)/서버·임시(☁) 표시
- 오디오북: 이어 듣기·위치 동기화, 백그라운드로 폰에 받기(트랙별, 와이파이 전용), 받기 관리
- 소리 내 읽기(TTS), 하이라이트·메모·내보내기, 본문 검색·책갈피, 찾아보기(사전·번역)
- 독서 통계(들은 시간 포함), 읽은 위치 동기화(KOReader 방식), 백업
- 받은 파일은 앱 안에만, 오디오북은 기기 키로 암호화

## 0.1.102

## 0.1.101

- 책 정보의 용량: 스트리밍 오디오북은 "스트리밍 (폰에 없음)", 일부만 받은 책은 "(일부 받음)"

## 0.1.100
